The web page and the print deck embed these fonts as base64 woff2. Both families are licensed under the SIL Open Font License 1.1; the licence text ships beside them here.

| `IBMPlexMono-400.woff2`, `IBMPlexMono-600.woff2` | IBM Plex Mono, © 2017 IBM Corp. (Reserved Font Name "Plex") | [IBMPlexMono-OFL.txt](IBMPlexMono-OFL.txt) |

The OFL allows embedding and redistribution with the game. It doesn't allow selling the fonts on their own, and a modified version can't use the Reserved Font Name.
